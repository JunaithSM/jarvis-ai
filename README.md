# Jarvis AI

**AI-powered coding tutor environment designed for deep learning.**

## Overview

Jarvis AI is a distraction-free, IDE-like environment that pairs a robust code editor with an intelligent AI mentor. The system is designed to help users learn algorithms and coding concepts through interactive guidance.

## Features

- **Intelligent AI Mentor**: Markdown-rich chat interface with progressive hints.
- **Dual-Mode UI**: Toggle between "Study Comfort" (Dark) and "Paper Focus" (Light) themes.
- **Integrated Environment**: Vertical split layout with Code Editor (CodeMirror 6) and Terminal.
- **Production Ready**: Built with React, Tailwind CSS, and Framer Motion.

## Tech Stack

- **Frontend**: React.js, Tailwind CSS, CodeMirror, Framer Motion
- **Backend**: Python (Flask/FastAPI)
- **Layout**: React Resizable Panels

## Setup

1. Clone the repository: `git clone https://github.com/JunaithSM/jarvis-ai.git`
2. Install dependencies: `npm install` (Frontend)
3. Start the dev server: `npm start`
